2. Padding: espacio por dentro

Compara dos párrafos con el mismo contenido.

Este es el contenido de mi caja.

Este es el contenido de mi caja.

Qué estamos viendo

El segundo párrafo tiene 24px de espacio interior por cada lado. El fondo amarillo se pinta también en el padding. El tamaño de las letras no cambia.

El HTML del ejemplo

<p class="sin-padding">Este es el contenido de mi caja.</p>
<p class="con-padding">Este es el contenido de mi caja.</p>

El CSS del ejemplo

p { background-color: lightyellow; border: 3px solid steelblue; }
.sin-padding { padding: 0; }
.con-padding { padding: 24px; }

Prueba un cambio

Cambia 24px por 40px y observa la distancia entre el texto y el borde.
