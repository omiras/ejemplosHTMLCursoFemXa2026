MODELO DE CAJA / 01

Shorthand: una propiedad resume varias

Podemos escribir cada lado por separado o utilizar una propiedad abreviada. Ambas versiones de este ejemplo producen el mismo resultado.

Propiedades separadas

.caja {
    padding-top: 20px;
    padding-right: 20px;
    padding-bottom: 20px;
    padding-left: 20px;
}

Forma abreviada

.caja {
    padding: 20px;
}

Una declaración por línea. Un shorthand puede contener varios valores dentro de esa misma declaración.

Ver ejemplo en el navegador

MODELO DE CAJA / 02

Margin con un valor

El mismo margen en los cuatro lados.

Forma abreviada

.caja {
    margin: 20px;
}

Propiedades separadas

.caja {
    margin-top: 20px;
    margin-right: 20px;
    margin-bottom: 20px;
    margin-left: 20px;
}

20px arriba · 20px derecha · 20px abajo · 20px izquierda.

Ver ejemplo en el navegador

MODELO DE CAJA / 03

Margin con dos valores

Primero arriba y abajo. Después izquierda y derecha.

Forma abreviada

.caja {
    margin: 10px 40px;
}

Propiedades separadas

.caja {
    margin-top: 10px;
    margin-right: 40px;
    margin-bottom: 10px;
    margin-left: 40px;
}

10px verticales · 40px horizontales. No significa «arriba y derecha».

Ver ejemplo en el navegador

MODELO DE CAJA / 04

Margin con tres valores

Arriba → izquierda y derecha → abajo.

Forma abreviada

.caja {
    margin: 10px 40px 30px;
}

Propiedades separadas

.caja {
    margin-top: 10px;
    margin-right: 40px;
    margin-bottom: 30px;
    margin-left: 40px;
}

El valor central se utiliza en los dos lados horizontales.

Ver ejemplo en el navegador

MODELO DE CAJA / 05

Margin con cuatro valores

Empieza arriba y sigue el sentido de las agujas del reloj: arriba → derecha → abajo → izquierda.

Forma abreviada

.caja {
    margin: 10px 20px 30px 40px;
}

Propiedades separadas

.caja {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 30px;
    margin-left: 40px;
}

TOP → RIGHT → BOTTOM → LEFT.

Ver ejemplo en el navegador

MODELO DE CAJA / 06

Padding sigue el mismo orden

Los valores se reparten igual que en margin. La diferencia es dónde se aplica el espacio: padding está dentro del borde.

Forma abreviada

.caja {
    padding: 10px 40px;
}

Propiedades separadas

.caja {
    padding-top: 10px;
    padding-right: 40px;
    padding-bottom: 10px;
    padding-left: 40px;
}

El amarillo es el fondo de la caja: también ocupa el padding.

Ver ejemplo en el navegador

MODELO DE CAJA / 07

Padding con cuatro valores

Arriba, derecha, abajo e izquierda. Cada lado puede tener una medida distinta.

Forma abreviada

.caja {
    padding: 10px 20px 30px 40px;
}

Propiedades separadas

.caja {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}

Con uno, dos o tres valores se repite exactamente la distribución que hemos visto para margin.

Ver ejemplo en el navegador

MODELO DE CAJA / 08

Border combina tres características

Aquí los valores no representan lados: representan grosor, estilo y color del borde.

Forma abreviada

.caja {
    border: 4px solid steelblue;
}

Propiedades separadas

.caja {
    border-width: 4px;
    border-style: solid;
    border-color: steelblue;
}

4px = grosor · solid = estilo · steelblue = color. Afecta a los cuatro lados.

Ver ejemplo en el navegador

MODELO DE CAJA / 09

El estilo del borde importa

Un grosor y un color no bastan para mostrar un borde nuevo: su estilo inicial es none.

Sin estilo de borde

.caja {
    border-width: 4px;
    border-color: steelblue;
}

Con estilo de borde

.caja {
    border-width: 4px;
    border-style: solid;
    border-color: steelblue;
}

En la derecha sí hay borde. Otros estilos que podemos probar: dashed y dotted.

Ver ejemplo en el navegador

MODELO DE CAJA / 10

Un borde en un solo lado

Podemos abreviar solo el borde inferior, sin añadir los otros tres.

Forma abreviada

.caja {
    border-bottom: 4px solid steelblue;
}

Propiedades separadas

.caja {
    border-bottom-width: 4px;
    border-bottom-style: solid;
    border-bottom-color: steelblue;
}

También existen border-top, border-right y border-left.

Ver ejemplo en el navegador

MODELO DE CAJA / 11

Grosor distinto en cada lado

border-width admite de uno a cuatro valores, con el mismo reparto por lados que margin y padding.

Forma abreviada

.caja {
    border-style: solid;
    border-color: steelblue;
    border-width: 2px 4px 8px 12px;
}

Propiedades separadas

.caja {
    border-style: solid;
    border-color: steelblue;
    border-top-width: 2px;
    border-right-width: 4px;
    border-bottom-width: 8px;
    border-left-width: 12px;
}

border: 4px solid blue combina características. border-width: 2px 4px 8px 12px reparte grosores entre lados.

Ver ejemplo en el navegador

MODELO DE CAJA / 12

El orden de las declaraciones cuenta

El shorthand asigna valores a todas las propiedades que resume. Después podemos cambiar un lado concreto.

Primero lo general

.caja {
    padding: 20px;
    padding-left: 50px;
}

Primero el lado concreto

.caja {
    padding-left: 50px;
    padding: 20px;
}

Izquierda: 50px a la izquierda y 20px en el resto. Derecha: 20px en todos los lados. En estas reglas, la última declaración decide cada valor repetido.

Ver ejemplo en el navegador

Prueba a desarrollar los shorthands

Escribe las propiedades por separado antes de abrir la respuesta.

Forma abreviada

    margin: 8px 24px;

    border: 3px dotted darkgreen;
