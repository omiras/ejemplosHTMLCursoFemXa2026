4. Elegir un lado concreto

Podemos cambiar cada lado por separado con los nombres completos.

Dentro: 10px arriba, 20px a la derecha, 30px abajo y 40px a la izquierda.

Fuera: 30px arriba y 60px a la izquierda. Dentro: 10px en cada lado.

Qué estamos viendo

top = arriba · right = derecha · bottom = abajo · left = izquierda. Padding cambia la distancia del contenido al borde; margin cambia la separación exterior.

El HTML del ejemplo

<p class="espacio-interior">Dentro: 10px arriba, 20px a la derecha, 30px abajo y 40px a la izquierda.</p>
<p class="espacio-exterior">Fuera: 30px arriba y 60px a la izquierda. Dentro: 10px en cada lado.</p>

El CSS del ejemplo

p { background-color: lightyellow; border: 3px solid steelblue; margin: 0; }
.espacio-interior { padding-top: 10px; padding-right: 20px; padding-bottom: 30px; padding-left: 40px; }
.espacio-exterior { padding: 10px; margin-top: 30px; margin-left: 60px; }

Prueba un cambio

Cambia padding-left a 80px en el primer párrafo y margin-left a 100px en el segundo. Compara qué se mueve.
