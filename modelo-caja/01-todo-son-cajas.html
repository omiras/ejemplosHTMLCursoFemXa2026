1. Los elementos también son cajas

Un borde permite ver el espacio que ocupa cada elemento.

Mi primera caja

Este párrafo también es una caja.

  • Una lista tiene su propia caja.
  • Sus elementos también ocupan espacio.
Este pie de página tiene un borde morado.

Qué estamos viendo

El borde rodea el elemento, no cada letra. Estas etiquetas se muestran como bloques por defecto: empiezan en una línea nueva y normalmente ocupan el ancho disponible.

El HTML del ejemplo

<h1>Mi primera caja</h1>
<p>Este párrafo también es una caja.</p>
<ul>
    <li>Una lista tiene su propia caja.</li>
    <li>Sus elementos también ocupan espacio.</li>
</ul>
<footer>Este pie de página tiene un borde morado.</footer>

El CSS del ejemplo

h1 { border: 3px solid steelblue; }
p { border: 3px solid seagreen; }
ul { border: 3px solid darkorange; }
footer { border: 3px solid purple; }

Prueba un cambio

Cambia el borde del párrafo de 3px a 8px. Prueba dotted en lugar de solid.
