3. Margin: espacio por fuera

El margen separa una caja de lo que tiene alrededor.

Primer párrafo: sin margen.

Segundo párrafo: 40px de margen a la izquierda y debajo.

Tercer párrafo: sin margen.

Qué estamos viendo

El hueco blanco a la izquierda y debajo del segundo párrafo es margen: está fuera del borde. El espacio amarillo entre el texto y el borde es padding. Quitamos los márgenes iniciales con margin: 0; aquí solo el segundo párrafo aporta margen vertical.

El HTML del ejemplo

<p class="sin-margen">Primer párrafo: sin margen.</p>
<p class="con-margen">Segundo párrafo: 40px de margen a la izquierda y debajo.</p>
<p class="sin-margen">Tercer párrafo: sin margen.</p>

El CSS del ejemplo

p { background-color: lightyellow; border: 3px solid steelblue; padding: 12px; margin: 0; }
.sin-margen { margin-left: 0; }
.con-margen { margin-left: 40px; margin-bottom: 40px; }

Prueba un cambio

Cambia margin-bottom a 80px: aumenta la separación con el tercer párrafo, no el espacio interior.
