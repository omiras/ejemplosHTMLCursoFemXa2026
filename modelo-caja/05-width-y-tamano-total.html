5. Width: ¿cuánto mide la caja?

Por defecto, width indica el ancho del contenido. El padding y el borde se suman.

Contenido de 240px de ancho.

Contenido de 240px de ancho, con padding y borde añadidos.

Qué estamos viendo

Primera caja: 240px. Segunda caja de borde a borde: 5 + 20 + 240 + 20 + 5 = 290px. El margen horizontal, si lo añadimos, ocupa espacio exterior adicional. Este ejemplo conserva el modelo inicial content-box.

El HTML del ejemplo

<p class="solo-contenido">Contenido de 240px de ancho.</p>
<p class="con-espacios">Contenido de 240px de ancho, con padding y borde añadidos.</p>

El CSS del ejemplo

p { width: 240px; margin: 0; background-color: lightyellow; }
.solo-contenido { padding: 0; border: 0; }
.con-espacios { padding: 20px; border: 5px solid steelblue; }

Prueba un cambio

Cambia el padding a 10px. El ancho de borde a borde será 270px.
