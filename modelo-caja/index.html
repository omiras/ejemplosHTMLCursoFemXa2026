Contenido, espacio interior (padding), borde (border) y espacio exterior (margin).

Cada ejemplo incluye el resultado, la explicación, el código y un cambio pequeño para probar en VS Code.

Cómo explorar cada ejemplo

  • Localiza el borde y lee las reglas CSS.
  • Cambia un solo valor, guarda y compara.
  • Inspecciona el elemento y busca el diagrama del modelo de caja.

El quinto ejemplo amplía el cálculo del ancho. Puedes empezar solo con los cuatro primeros. Los catálogos no incluyen explicaciones.

En los ejemplos didácticos, las reglas que estudiamos están en style. Las explicaciones usan estilos en línea para mantenerse legibles.
