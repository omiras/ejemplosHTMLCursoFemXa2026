CSS / 01

CSS: dar estilo al contenido

HTML organiza el contenido; CSS decide cómo se presenta. Hoy queremos comprender qué regla se aplica y por qué.

HTML

<p class="ingreso">Ingreso: +1.200 €</p>

CSS

.ingreso { color: green; }
● ● ●   Vista de navegador · ejemplo.html

Mismo HTML, distintas decisiones de presentación.

CSS / 02

Leer una regla CSS

Selector → a quién. Propiedad → qué cambiamos. Valor → cómo lo cambiamos.

CSS

p {
    color: green;
    font-size: 24px;
}

Cada declaración termina con punto y coma. Las llaves agrupan las declaraciones.

CSS / 03

De estilos en línea a reglas compartidas

Un atributo style cambia ese elemento. Una regla permite compartir decisiones.

HTML

<p style="color: green;">Ingreso: +100 €</p>
<p style="color: green;">Ingreso: +200 €</p>
● ● ●   Vista de navegador · ejemplo.html

Si repetimos la misma decisión en muchos elementos, una clase nos permite mantenerla en un solo lugar.

CSS / 04

Dónde escribir CSS

Para ejemplos pequeños, podemos usar <style> dentro de <head>. Para separar archivos, usamos <link>.

HTML

<head>
    <link rel="stylesheet" href="estilos.css">
</head>

CSS

/* Archivo estilos.css */
p {
    font-size: 22px;
}
● ● ●   Vista de navegador · ejemplo.html

El archivo CSS contiene reglas, sin etiquetas <style>. La ruta parte del HTML; guarda ambos archivos.

CSS / 06

Clases: agrupar por una característica

class identifica un grupo. El nombre lo elegimos nosotros y puede repetirse.

HTML

<p class="ingreso">Ingreso de nómina: +1.200 €</p>
<p class="retirada">Retirada en cajero: −40 €</p>
<p class="ingreso">Ingreso de transferencia: +75 €</p>

CSS

.ingreso { color: green; }
.retirada { color: lightcoral; }
● ● ●   Vista de navegador · ejemplo.html

En HTML: class="ingreso", sin punto. En CSS: .ingreso, con punto.

CSS / 07

Una regla, varios movimientos

Cada párrafo recibe el estilo de su clase. Cambiar una regla actualiza todos los elementos que coinciden.

HTML

<p class="ingreso">Ingreso de nómina: +1.200 €</p>
<p class="retirada">Retirada en cajero: −40 €</p>
<p class="ingreso">Ingreso de transferencia: +75 €</p>
<p class="retirada">Retirada en cajero: −20 €</p>

CSS

.ingreso { color: green; }
.retirada { color: lightcoral; }
● ● ●   Vista de navegador · ejemplo.html

Abre ejemplo-clases-css.html. El texto y el signo también distinguen los movimientos: no dependemos solo del color.

CSS / 08

Probar una clase

Añade otro movimiento con una clase existente. No necesitas escribir otra regla.

HTML

<p class="ingreso">Ingreso de devolución: +30 €</p>

CSS

.ingreso { color: green; }
● ● ●   Vista de navegador · ejemplo.html

¿Qué ocurre si escribimos class=".ingreso"?

Mostrar explicación

No coincide con .ingreso: el punto pertenece al selector CSS, no al valor de class.

CSS / 09

Estilos generales y casos concretos

Primero establecemos características comunes; después cambiamos solo las que dependen del grupo.

HTML

<p class="ingreso">Ingreso: +100 €</p>
<p class="retirada">Retirada: −20 €</p>

CSS

p {
    font-size: 24px;
}
.ingreso { color: green; }
.retirada { color: lightcoral; }
● ● ●   Vista de navegador · ejemplo.html

Las reglas se combinan por propiedad. Las clases de color no eliminan el tamaño de letra.

CSS / 10

Currículum: texto y fondos

En el currículum de PIMEC aparecen títulos centrados, mayúsculas y fondos por apartados.

HTML

<h1>Mi currículum</h1>
<h2>Experiencia</h2>
<p>Formación y desarrollo web.</p>

CSS

body { background-color: #d7dfe3; }
h1 { text-align: center; text-transform: uppercase; }
h2 { background-color: #809ba8; }
p { background-color: #b9c9d0; }
● ● ●   Vista de navegador · ejemplo.html

color cambia el texto; background-color cambia el fondo del elemento.

CSS / 11

Greguerías: párrafos de distintos grupos

La carpeta usa infancia, naturaleza, literatura y numeros. El mecanismo es el mismo que en los movimientos.

HTML

<p class="infancia">Una frase sobre la infancia.</p>
<p class="naturaleza">Una frase sobre la naturaleza.</p>
<p class="infancia">Otra frase sobre la infancia.</p>

CSS

body { background-color: #258b50; }
.infancia { color: white; font-style: italic; }
.naturaleza { color: #ffdbac; font-family: Arial, sans-serif; }
● ● ●   Vista de navegador · ejemplo.html

Un nombre como infancia explica el grupo y permite cambiar su presentación después.

CSS / 12

Tipografía: propiedades frecuentes

Elige una propiedad según el cambio que necesites.

HTML

<p class="destacado">Una frase destacada.</p>

CSS

.destacado {
    font-family: Arial, sans-serif;
    font-size: 28px;
    font-weight: bold;
    font-style: italic;
    text-decoration: underline;
}
● ● ●   Vista de navegador · ejemplo.html

font-weight: grosor · font-style: cursiva · text-decoration: decoración. No hace falta usarlas todas juntas.

CSS / 13

Películas: una clase en parte de una línea

span permite marcar un fragmento. details y summary aportan el comportamiento de desplegar sin JavaScript.

HTML

<details>
    <summary><span class="impar">👻 🚫</span></summary>
    <p>Los cazafantasmas</p>
</details>
<details>
    <summary><span class="par">🐒 🌍</span></summary>
    <p>El planeta de los simios</p>
</details>

CSS

.impar { background-color: #ffc9e9; }
.par { background-color: white; }
summary { font-size: 36px; }
● ● ●   Vista de navegador · ejemplo.html

En este ejemplo el fondo colorea el span, no toda la fila.

CSS / 14

La jerarquía HTML explica la herencia

Los elementos están unos dentro de otros. Algunas propiedades pasan del padre a sus descendientes.

HTML

<main>
    <section>
        <h2>Movimientos</h2>
        <p>Ingreso: +100 €</p>
    </section>
</main>

CSS

main {
    color: darkblue;
    font-family: Arial, sans-serif;
}
● ● ●   Vista de navegador · ejemplo.html

h2 y p heredan el color y la familia tipográfica en este ejemplo.

CSS / 15

No todas las propiedades se heredan

color y font-family suelen heredarse. border, margin y padding no se heredan por defecto.

HTML

<section>
    <p>Estoy dentro de la sección.</p>
</section>

CSS

section {
    color: darkblue;
    border: 3px solid orange;
    padding: 20px;
}
● ● ●   Vista de navegador · ejemplo.html

El párrafo tiene texto azul, pero no recibe su propio borde naranja ni su propio padding de 20px.

CSS / 16

Un estilo directo sustituye al heredado

La herencia aporta un valor cuando el elemento no tiene otro valor establecido por la cascada.

HTML

<section>
    <p class="ingreso">Ingreso: +100 €</p>
    <p>Información de la cuenta.</p>
</section>

CSS

section { color: darkblue; }
.ingreso { color: green; }
● ● ●   Vista de navegador · ejemplo.html

El primer párrafo es verde. El segundo hereda azul. No se compara la especificidad de section con .ingreso: apuntan a elementos diferentes.

CSS / 17

Especificidad: etiqueta y clase

Si dos reglas normales del mismo origen y capa asignan la misma propiedad al mismo elemento, la clase tiene más especificidad que la etiqueta.

HTML

<p class="ingreso">Ingreso: +100 €</p>

CSS

.ingreso { color: green; }
p { color: blue; }
● ● ●   Vista de navegador · ejemplo.html

¿De qué color será este párrafo aunque p esté después?

Mostrar explicación

Verde: .ingreso tiene más especificidad que p.

CSS / 18

Si empatan, decide el orden

Entre declaraciones comparables con la misma especificidad gana la última para esa propiedad.

HTML

<p class="ingreso">Ingreso: +100 €</p>

CSS

.ingreso { color: green; }
.ingreso { color: purple; }
● ● ●   Vista de navegador · ejemplo.html

El resultado es morado. No basta con decir «gana lo último»: antes hay que comprobar qué reglas compiten.

CSS / 19

Selectores que encontrarás

Una clase se puede reutilizar. Un id debe ser único dentro de la página.

HTML

<p id="aviso" class="ingreso">Ingreso pendiente.</p>

CSS

p { color: black; }
.ingreso { color: green; }
p.ingreso { color: darkgreen; }
#aviso { color: purple; }
● ● ●   Vista de navegador · ejemplo.html

Aquí gana #aviso. p.ingreso significa «párrafos con clase ingreso». Usa clases para grupos; no necesitas ids para resolver estos ejercicios.

CSS / 20

El inspector: comprobar, no adivinar

Clic derecho sobre un párrafo → Inspeccionar → panel Estilos / Styles.

1. Localiza su etiqueta y class. 2. Busca color. 3. Observa las declaraciones tachadas. 4. Consulta Calculado / Computed para ver el valor final. 5. Activa y desactiva una declaración.

CSS / 21

Probar estilos desde el navegador

En element.style puedes añadir una declaración en línea para explorar su efecto.

HTML

<p class="ingreso" style="color: purple;">Ingreso: +100 €</p>

CSS

.ingreso { color: green; }
● ● ●   Vista de navegador · ejemplo.html

Frente a nuestras reglas normales, el estilo en línea prevalece. Los cambios hechos en el inspector son temporales: cópialos al archivo y guarda. No necesitas !important para estos ejercicios.

CSS / 22

Espacios: dentro y fuera de la caja

Ampliación breve para separar apartados: padding es espacio interior; margin es espacio exterior.

HTML

<p class="aviso">Revisa los movimientos.</p>

CSS

.aviso {
    border: 2px solid darkblue;
    padding: 16px;
    margin: 24px;
}
● ● ●   Vista de navegador · ejemplo.html

Cambia cada valor por separado y observa qué distancia modifica.

CSS / 23

Resolver PIMEC paso a paso

Abre un ejercicio, identifica grupos y cambia pocas propiedades cada vez.

Currículum: fondos, títulos y alineación. Greguerías: clases y tipografía. Películas: fondos alternos y tamaño. Guarda, compara con la captura e inspecciona. No venimos a hacer webs perfectas: queremos entender las decisiones.

CSS / 24

Recursos y práctica final

Explica por qué dos párrafos de la misma etiqueta pueden tener colores distintos.

Cambia el color de todos los ingresos con una sola declaración. Añade un movimiento. Inspecciona una retirada y localiza la regla que le da color.

Mostrar explicación

HTML asigna class a cada grupo; CSS selecciona esa clase con un punto y define su color.
