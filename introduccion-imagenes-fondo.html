Una imagen de fondo con background-image

Un uso habitual es una portada: un contenedor con una imagen decorativa detrás de un título y un párrafo. El texto sigue siendo HTML y se puede seleccionar.

Abrir el ejemplo preparado para clase

1. Creamos el contenedor y su texto

<div class="portada">
    <h1>Escápate a la montaña</h1>
    <p>Descubre nuestras rutas de fin de semana.</p>
</div>

2. Añadimos la imagen desde CSS

.portada {
    background-color: #183747;
    background-image: url("imagenes/paisaje.svg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
    color: white;
    text-align: center;
    padding: 80px 20px;
}
  • background-image: indica la ruta de la imagen con url(...). Aquí la ruta parte del HTML porque el CSS está dentro de él. En un archivo CSS separado, partiría de ese archivo.
  • background-size: cover: cubre todo el contenedor conservando las proporciones; puede recortar parte de la imagen.
  • background-position: center: centra la imagen dentro del contenedor.
  • background-repeat: no-repeat: evita que la imagen se repita como un mosaico.
  • background-color: mantiene un fondo oscuro si la imagen no carga.
  • color y text-align: hacen que el texto sea blanco y esté centrado horizontalmente.
  • padding: 80px 20px: deja 80 píxeles por arriba y abajo y 20 a cada lado. El contenido y este espacio dan altura al contenedor.

No necesitamos fijar una altura ni usar flex: el título y el párrafo se colocan uno debajo del otro de forma natural.

3. Probamos un cambio cada vez

  1. Abre el ejemplo en el navegador y su código en el editor.
  2. Cambia el padding de 80px a 40px. Guarda y observa la altura.
  3. Cambia center por left en text-align.
  4. Desactiva background-size: cover para observar la imagen con su tamaño original. Después desactiva background-repeat: no-repeat y ensancha la ventana para ver cómo se repite cuando queda espacio.

La imagen de fondo es decorativa y no ocupa espacio propio. Si la imagen comunica información necesaria para comprender la página, utiliza <img> con un texto alternativo adecuado.
