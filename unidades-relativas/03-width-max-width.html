3. Width y max-width: una caja adaptable

Resultado

Una lectura cómoda

Esta caja ocupa el 90% del espacio disponible, pero nunca supera los 600 píxeles de ancho.

Qué estamos viendo

width: 90% hace que la caja se adapte al contenedor. max-width: 600px impone un límite. Con un contenedor de 1000px, el 90% sería 900px, pero el resultado se limita a 600px. Con uno de 400px, la caja mide 360px.

margin: 0 auto reparte por igual el espacio horizontal sobrante y centra la caja. max-width es una propiedad, no una unidad. Todavía no hemos añadido padding ni borde.

CSS del ejemplo

.caja {
    width: 90%;
    max-width: 600px;
    margin: 0 auto;
    background-color: #eef4fa;
}

HTML del ejemplo

<div class="caja">
    <h2>Una lectura cómoda</h2>
    <p>Esta caja ocupa el 90% del espacio disponible, pero nunca supera los 600 píxeles de ancho.</p>
</div>

Un cambio para probar

Prueba con una ventana ancha y luego estrecha. Desactiva max-width en el inspector y observa cómo la caja vuelve a ocupar siempre el 90%.

Guarda, recarga e inspecciona la caja. El código que estudiamos está en el bloque style; las explicaciones usan estilos en línea.
