1. Porcentajes: el ancho depende del contenedor

Resultado

80% del contenedor grande
80% del contenedor pequeño

Qué estamos viendo

Las dos barras tienen width: 80%, pero sus padres tienen anchos distintos. Si un padre mide 500px, su barra mide 400px; si mide 300px, la barra mide 240px. El porcentaje se calcula respecto al ancho del contenido del contenedor, no siempre respecto a la ventana.

En este ejemplo las barras no tienen padding ni borde, así que el cálculo se ve directamente.

CSS del ejemplo

.contenedor {
    width: 100%;
    background-color: #e4e9ef;
    margin-bottom: 20px;
}
.estrecho {
    width: 60%;
}
.barra {
    width: 80%;
    background-color: #245b87;
    color: white;
}

HTML del ejemplo

<div class="contenedor">
    <div class="barra">80% del contenedor grande</div>
</div>
<div class="contenedor estrecho">
    <div class="barra">80% del contenedor pequeño</div>
</div>

Un cambio para probar

Cambia el 80% de .barra por 50%. Después reduce la ventana: ambas barras siguen ocupando la mitad de su propio contenedor.

Guarda, recarga e inspecciona la caja. El código que estudiamos está en el bloque style; las explicaciones usan estilos en línea.
