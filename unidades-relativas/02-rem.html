2. Rem: la referencia es html

Resultado

Texto en rem

Mi texto mide 1rem y mi espacio interior también.

Mi texto y mi espacio interior están fijados en 16px.

Qué estamos viendo

Con html { font-size: 16px; }, 1rem equivale a 16px y 2rem a 32px. Si html pasa a 20px, equivalen a 20px y 40px. La tarjeta con valores en píxeles mantiene sus tamaños declarados.

Rem depende de html, aunque el elemento padre tenga otro tamaño de letra. También sirve para padding y margin. Aquí fijamos 16px para facilitar las cuentas; sin esa regla se utiliza el tamaño raíz configurado en el navegador.

CSS del ejemplo

html {
    font-size: 16px;
}
.tarjeta-rem {
    font-size: 1rem;
    padding: 1rem;
    margin-bottom: 1rem;
    background-color: #eef7f1;
}
.tarjeta-rem h2 {
    font-size: 2rem;
    margin: 0 0 1rem;
}
.tarjeta-px {
    font-size: 16px;
    padding: 16px;
    background-color: #fff3de;
}

HTML del ejemplo

<div class="tarjeta-rem">
    <h2>Texto en rem</h2>
    <p>Mi texto mide 1rem y mi espacio interior también.</p>
</div>
<div class="tarjeta-px">
    <p>Mi texto y mi espacio interior están fijados en 16px.</p>
</div>

Un cambio para probar

Cambia solo font-size de html a 20px. Compara el título, el texto y el padding. Después añade font-size: 30px a .tarjeta-rem: el título de 2rem seguirá tomando como referencia html.

Guarda, recarga e inspecciona la caja. El código que estudiamos está en el bloque style; las explicaciones usan estilos en línea.
