4. Border-box: incluir padding y borde en el ancho

Resultado

Content-box: la caja sobresale del marco gris

100% + padding + borde

Border-box: todo cabe dentro del marco

El 100% incluye padding y borde

Qué estamos viendo

Con un marco de 300px, content-box da 300px al contenido y añade 40px de padding y 10px de borde: la caja exterior mide 350px. Con border-box, el exterior mide 300px y quedan 250px para el contenido.

El margin queda fuera en ambos casos. La primera caja desborda a propósito para mostrar el problema: no lo ocultamos con overflow.

CSS del ejemplo

.marco {
    width: 100%;
    background-color: #e4e9ef;
    margin-bottom: 24px;
}
.caja {
    width: 100%;
    padding: 20px;
    border: 5px solid #245b87;
    background-color: #eaf3fa;
}
.content-box {
    box-sizing: content-box;
}
.border-box {
    box-sizing: border-box;
}

HTML del ejemplo

<h3>Content-box: la caja sobresale del marco gris</h3>
<div class="marco">
    <div class="caja content-box">100% + padding + borde</div>
</div>
<h3>Border-box: todo cabe dentro del marco</h3>
<div class="marco">
    <div class="caja border-box">El 100% incluye padding y borde</div>
</div>

Un cambio para probar

Inspecciona ambas cajas y compara el modelo de caja. Cambia .content-box a box-sizing: border-box para eliminar el desbordamiento. Prueba después con la ventana estrecha.

Guarda, recarga e inspecciona la caja. El código que estudiamos está en el bloque style; las explicaciones usan estilos en línea.
