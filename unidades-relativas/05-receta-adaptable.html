5. Aplicación: una receta adaptable

Resultado

Tostada de tomate

Una receta sencilla para empezar el día.

Ingredientes

  • Una rebanada de pan
  • Un tomate maduro
  • Aceite de oliva

Preparación

  1. Tuesta el pan.
  2. Ralla el tomate y repártelo sobre la tostada.
  3. Añade un chorrito de aceite de oliva.

Qué estamos viendo

Combinamos las cuatro ideas: 90% para adaptar el ancho, 640px como límite, rem para texto y espacios, y border-box para incluir padding y borde dentro del ancho. No hay altura fija: la receta crece con el contenido.

CSS del ejemplo

html {
    font-size: 16px;
}
.receta {
    box-sizing: border-box;
    width: 90%;
    max-width: 640px;
    margin: 2rem auto;
    padding: 1.5rem;
    border: 2px solid #d7c6ac;
    background-color: #fff8ed;
    font-size: 1rem;
}
.receta h2 {
    font-size: 2rem;
    margin: 0 0 1rem;
}
.receta h3 {
    font-size: 1.25rem;
}

HTML del ejemplo

<article class="receta">
    <h2>Tostada de tomate</h2>
    <p>Una receta sencilla para empezar el día.</p>
    <h3>Ingredientes</h3>
    <ul>
        <li>Una rebanada de pan</li>
        <li>Un tomate maduro</li>
        <li>Aceite de oliva</li>
    </ul>
    <h3>Preparación</h3>
    <ol>
        <li>Tuesta el pan.</li>
        <li>Ralla el tomate y repártelo sobre la tostada.</li>
        <li>Añade un chorrito de aceite de oliva.</li>
    </ol>
</article>

Un cambio para probar

Reduce la ventana hasta unos 320px y comprueba que la receta cabe. Cambia html a 20px: aumentarán el texto y los espacios en rem, mientras el límite de 640px seguirá igual.

Guarda, recarga e inspecciona la caja. El código que estudiamos está en el bloque style; las explicaciones usan estilos en línea.
