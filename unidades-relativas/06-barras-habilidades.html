Qué estamos viendo

Cada pista gris ocupa el ancho disponible dentro de .habilidades. La barra azul ocupa un porcentaje de esa pista. Si la pista mide 400px, la barra de HTML mide 320px; si pasa a 200px, mide 160px.

border-box evita que el padding de la barra se sume a su porcentaje. El texto expresa también el valor para no depender solo del color o del ancho.

CSS del ejemplo

html {
    font-size: 16px;
}
.habilidades {
    box-sizing: border-box;
    width: 90%;
    max-width: 600px;
    margin: 2rem auto;
    padding: 1rem;
    border: 2px solid #cbd8e1;
}
.pista {
    background-color: #e4e9ef;
    margin-bottom: 1rem;
}
.nivel {
    box-sizing: border-box;
    padding: 0.5rem;
    background-color: #245b87;
    color: white;
    font-size: 1rem;
}
.html {
    width: 80%;
}
.css {
    width: 60%;
}
.javascript {
    width: 40%;
}

HTML del ejemplo

<div class="habilidades">
    <h2>Mis habilidades</h2>
    <p>HTML · 80%</p>
    <div class="pista"><div class="nivel html">80%</div></div>

    <div class="pista"><div class="nivel css">60%</div></div>
    <p>JavaScript · 40%</p>
    <div class="pista"><div class="nivel javascript">40%</div></div>
</div>

Un cambio para probar

Cambia la habilidad CSS al 70%, tanto en la regla como en sus dos textos. Reduce la ventana y observa que la proporción se mantiene. Inspecciona la pista y calcula el ancho esperado de su barra.

Guarda, recarga e inspecciona la caja. El código que estudiamos está en el bloque style; las explicaciones usan estilos en línea.
